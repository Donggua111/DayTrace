# Security Policy

**Languages / 语言：** [English](#security-policy) · [简体中文](#简体中文)

## Reporting a vulnerability

Please report suspected security vulnerabilities privately through GitHub
Security Advisories:

[Report a vulnerability for Donggua111/DayTrace](https://github.com/Donggua111/DayTrace/security/advisories/new)

Private vulnerability reporting has been enabled for this repository, as
confirmed by the repository owner. Do not disclose vulnerabilities through
public GitHub Issues, discussions, or other public channels. Do not include
real activity data, databases, backups, credentials, or other people's private
information in a report.

The `main` branch is the project's primary maintenance branch. DayTrace has
not yet published a formal release or established supported release versions;
no support coverage should be inferred for unreleased builds or other branches.
Maintenance and vulnerability response are best-effort. There is no guaranteed
acknowledgment, remediation, or response time.

Relevant reports include unintended collection or disclosure of activity
data, unsafe backup or restore behavior, IPC or Native Messaging boundary
failures, privilege or permission escalation, and dependency or build-chain
vulnerabilities. Please provide a concise impact description and reproducible
steps using synthetic data where possible. Coordinate public disclosure with
the maintainers through the private advisory.

## Safe handling

Never include raw keystrokes, typed text, key sequences, full URLs, page titles,
page contents, audio, clipboard data, real databases, backups, or signing
materials in a report. Use synthetic test data. Do not test against another
person's machine or profile without authorization.

## 简体中文

### 漏洞报告

请通过 GitHub Security Advisories 私密报告疑似安全漏洞：

[向 Donggua111/DayTrace 私密报告漏洞](https://github.com/Donggua111/DayTrace/security/advisories/new)

仓库所有者已确认开启 Private Vulnerability Reporting。请勿通过公开
GitHub Issue、讨论区或其他公开渠道披露漏洞。报告中不得包含真实活动数据、
数据库、备份、凭据或他人的隐私信息。

项目以 `main` 分支作为主要维护对象。DayTrace 尚未发布正式版本，也未建立
受支持版本列表；不得据此推断未发布构建或其他分支享有支持承诺。维护和漏洞
响应采取尽力而为（best-effort）方式，不保证确认、修复或响应时限。

报告范围包括活动数据意外收集或泄露、备份/恢复安全问题、IPC 或 Native
Messaging 边界失效、权限提升，以及依赖或构建链漏洞。请简要说明影响并提供
可复现步骤，尽可能使用合成数据；公开披露前请通过私密 Advisory 与维护者协调。

### 安全处理

报告中不得包含原始按键、输入文本、按键序列、完整 URL、网页标题或内容、
音频、剪贴板数据、真实数据库、备份或签名材料。请使用合成测试数据；未经授权，
不得在他人的设备或用户配置上测试。
