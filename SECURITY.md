# Security Policy

**Languages / 语言：** [English](#security-policy) · [简体中文](#简体中文)

DayTrace is in pre-release development. No public release channel or supported-version policy has been established yet.

## Reporting a vulnerability

Please do not post suspected vulnerabilities, private activity data, database files, backups, or credentials in a public issue. Contact the repository maintainer through a private channel associated with the repository owner. Include a concise impact description and reproducible steps that do not expose real user data. A dedicated security contact will be published before public launch.

## Scope and response

Relevant reports include unintended collection or disclosure of activity data, unsafe backup/restore behavior, IPC or Native Messaging boundary failures, privilege/permission escalation, and dependency or build-chain vulnerabilities. The maintainer will acknowledge reports and coordinate a fix and disclosure timeline; no response-time SLA is promised during this pre-release period.

## Safe handling

Do not include raw keystrokes, typed text, full URLs, page titles, audio, clipboard data, real databases, backups, or signing materials in reports. Use synthetic test data. Do not test against another person's machine or profile without authorization.

## 简体中文

DayTrace 仍处于发布前开发阶段，尚未建立公开发布渠道或受支持版本政策。

### 漏洞报告

请勿在公开 issue 中发布疑似漏洞、个人活动数据、数据库、备份或凭据。请通过与仓库所有者关联的私密渠道联系维护者，并提供简洁的影响说明和不暴露真实用户数据的复现步骤。公开发布前会公布专用安全联系渠道。

### 范围与响应

相关报告包括：意外收集或泄露活动数据、不安全的备份/恢复行为、IPC 或 Native Messaging 边界问题、权限提升，以及依赖或构建链安全问题。维护者将确认报告并协调修复与披露时间；发布前阶段不承诺响应时限。

### 安全处理

报告中不得包含原始按键、输入文本、完整 URL、网页标题、音频、剪贴板数据、真实数据库或签名材料。请使用合成测试数据；未经授权不得在他人的设备或浏览器配置上测试。

Do not include raw keystrokes, typed text, full URLs, page titles, audio, clipboard data, real databases, or signing materials in reports. Use synthetic test data. Do not test against another person's machine or profile without authorization.
